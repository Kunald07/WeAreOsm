# 🌐 OSM Landing Page Clone

A modern and responsive landing page inspired by the **We Are OSM** website, built using **HTML, CSS, and JavaScript**. This project focuses on creating an engaging user experience with smooth animations, interactive navigation, and responsive layouts.

---

## 📌 Project Overview

This project recreates the look and feel of the OSM website while practicing modern frontend development concepts. It includes multiple content sections, animated effects, a responsive side navigation menu, sliders, and typing animations.

---

## 🚀 Features

* Responsive landing page design
* Animated side navigation menu
* Smooth scrolling between sections
* Interactive typing animation
* Image/content slider
* Modern UI with clean layout
* SVG icons and animated GIFs
* Mobile-friendly interface

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)

### Libraries Used

* GSAP (GreenSock Animation Platform)
* Typed.js
* Swiper.js
